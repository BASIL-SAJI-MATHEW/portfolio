I am Basil Saji Mathew, a Lua developer who builds FiveM resources, game server tooling and the automation around them. I work between Bengaluru, India and Abu Dhabi, UAE, and remotely, in English and Hindi.

What I build in Lua

  • FiveM client and server resources for ESX, QBCore, Qbox and standalone servers.
  • Performance-focused scripts that idle at 0.00ms in resmon: dynamic waits, zones instead of polling, cached natives.
  • Database-backed features using oxmysql with cooldowns, caching and safe writes.
  • Admin and safety tools such as weapon control, safe zones and logging.

How I work

I start by measuring: what does the script cost today, and where? I keep client code for presentation and input, and put validation on the server, because anything that touches money, items or permissions must never trust the client. I write plainly, document the config, and tell you what is and is not tested.

My guide How to Optimize FiveM Lua Scripts and Reach 0.00ms Idle explains the habits I use on every resource.
