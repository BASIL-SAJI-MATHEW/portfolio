My approach

Small, testable pieces; sensible defaults; and monitoring from day one. For example, the IP Whitelist Automation API manages firewall access with time-based rules and role-based permissions, and Portcullis ships with 118 automated tests and starts in observe mode so it cannot lock anyone out on day one.

I also run Altivora Hosting, so I deploy and operate what I build.
