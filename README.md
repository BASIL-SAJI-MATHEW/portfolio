# basilsajimathew.com

Personal portfolio of Basil Saji Mathew: Lua and FiveM development, backend automation and security tooling.

A static site with no build step. A scroll-driven WebGL scene (Three.js with bloom) flies through five stations as you scroll, with smooth scrolling (Lenis) and GSAP animation.

## Run locally

```
python -m http.server 8000
```

Open http://localhost:8000. Any static file server works.

## Structure

- `index.html`: content and metadata
- `style.css`: layout and theme
- `main.js`: 3D world, scroll choreography, UI motion
- `assets/`: favicon and social preview image
- `Basil_Saji_Mathew_CV.pdf`: resume download
